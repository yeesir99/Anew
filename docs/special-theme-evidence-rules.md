# 特殊主题证据规则

## 通用主题映射约束

普通主题只允许精确概念名称或明确的近义分类匹配；不得使用宽泛父级行业替代窄主题。映射策略版本为 3，主题成分缓存有效期为 7 天。缓存过期或策略版本不一致时必须重新采集。

来源优先级为 THS 精确概念成分页、EastMoney Push2 镜像主机精确概念成分页、Baidu Stock Market 逐股概念标签。每条映射必须记录 Provider、精确匹配名称、来源 URL 和采集时间。Baidu 接口不提供历史成分日期，只代表采集时的标签快照，不能用于历史回溯。Provider 覆盖率低于95%或传输失败时保持 partial/unavailable，不用人工猜测补齐。

## 烟草与大麻

此主题按“烟草”和“工业大麻”两个独立概念精确匹配。两个组件可以来自不同 Provider，但必须分别记录 Provider、板块/概念代码、来源链接和采集时间；只有两个组件都达到完整覆盖且精确命中时才合并。THS“烟草”板块定义侧重烟标企业及实控人为中国烟草的企业；“新型烟草(电子烟)”不自动并入。任一组件缺失时保持未映射，不用一般医药或宽泛大麻相关概念补齐。来源：[THS 烟草板块定义](https://q.10jqka.com.cn/gn/detail/code/308560/)；[THS 概念板块列表](https://q.10jqka.com.cn/gn/)。

## 参股民营银行

THS、EastMoney 或 Baidu 概念标签仅用于发现候选，不作为持股证明。正式成分必须来自 data/private_bank_equity_evidence.json，包含上市公司代码、被投资银行名称、关系类型、持股比例、披露日期、原始公告/定期报告 URL、披露类型和可核验摘录。没有披露证据的候选公司不能加入已验证成分。披露来源日期必须不晚于报告交易日，超过证据有效期则重新核验。

## 科创次新股

该主题不依赖 THS/EastMoney/Baidu 概念标签。直接使用上海证券交易所官方“科创板”股票名录中的证券代码和上市日期；只保留688/689代码，并按报告交易日计算上市是否未满一个日历年。上市日期覆盖率低于95%时保持 partial；缺少上市日期的证券不得加入。该规则避免概念板块页面被拦截或分类标签缺失导致漏项。来源：[上海证券交易所科创板股票列表](https://www.sse.com.cn/assortment/stock/list/share/)。

## 资金流持续性

5日与10日信号必须来自同一 Provider，才计算持续性方向。若周期分别由 EastMoney 和 THS 提供，持续性维度保持缺失；THS 净额不改名为 EastMoney 主力净流入。
