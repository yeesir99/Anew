# 特殊主题证据规则

## 通用主题映射约束

普通主题仅允许精确名称或明确的近义分类名称匹配；不再使用“半导体”“小金属”“医疗服务”“贸易”等宽泛父级行业替代更窄主题。映射策略版本为 2，旧版本缓存不会继续作为有效映射复用。覆盖率下降时保留未映射状态，不用扩大别名表补数量。

## 烟草与大麻

此主题按“烟草”和“工业大麻”两个独立概念精确匹配。优先使用 THS 概念名录和成分页；若 THS 页面对云端运行器返回 403，则回退到 EastMoney 概念名录，并要求组件名称精确匹配后再取成分。两个组件可以来自不同 Provider，但必须分别记录 Provider、板块代码和来源链接，只有两个组件均成功才合并。THS“烟草”板块定义侧重烟标企业及实控人为中国烟草的企业；“新型烟草(电子烟)”不自动并入。任一组件缺失时保持未映射，不用一般医药或宽泛大麻相关概念补齐。来源：[THS 烟草板块定义](https://q.10jqka.com.cn/gn/detail/code/308560/)；[THS 概念板块列表](https://q.10jqka.com.cn/gn/)。

## 参股民营银行

THS 概念板块仅用于发现候选，不作为持股证明。正式成分必须来自 `data/private_bank_equity_evidence.json`，字段要求见 [private-bank-evidence.md](private-bank-evidence.md)。空记录表示尚无可核验名单。

## 科创次新股

必须同时满足科创板证券代码（688/689）、精确概念板块“科创次新股”成员关系和有效 IPO 上市日期。成员来源优先 THS；THS 页面被云端网络拦截时，可回退到 EastMoney 名录中的同名概念，仍不得使用宽泛行业替代。期限采用 THS 板块定义“科创板上市、上市时间小于一年”，按一个日历年计算，而不是自行猜测天数；计算以报告交易日为基准，不以运行当天替代。来源：[THS 科创次新股板块定义](https://q.10jqka.com.cn/gn/detail/code/308699/)。

## 资金流持续性

5日与10日信号必须来自同一 Provider，才计算持续性方向。若周期分别由 EastMoney 和 THS 提供，持续性维度保持缺失；THS 净额不改名为 EastMoney 主力净流入。
